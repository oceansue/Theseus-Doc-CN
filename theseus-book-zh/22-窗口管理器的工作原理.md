# 窗口管理器的工作原理

## 设计

通常，创建/拥有窗口的应用程序和控制该窗口的窗口管理器需要共同访问这个窗口。应用程序需要在窗口的主体部分显示自己的内容，而窗口管理器则需要所有窗口的位置与深度排序信息才能渲染它们。

为了在应用程序与窗口管理器之间共享一个窗口，应用程序持有对该窗口的强引用（`Arc`），而窗口管理器则持有对同一个窗口的弱引用（`Weak`）。这样，窗口管理器就可以控制并管理一个窗口，而在概念上并不拥有它。

我们使用 `Mutex` 来包装每个窗口，使应用程序任务与窗口管理器任务能够安全地共同访问它。然而，`Mutex` 也带来了死锁的可能：当应用程序想要访问自己的窗口时，它必须获取 `Mutex` 锁、操作窗口，然后释放锁。如果应用程序不释放其窗口上的锁，窗口管理器就会被迫阻塞，直到锁被释放为止，从而无法执行窗口切换、事件分发或删除窗口等常规操作。

为了解决这个问题，我们定义了两个结构体：`Window` 和 `WindowInner`。`WindowInner` 只包含窗口管理器所需的信息。窗口管理器持有指向 `WindowInner` 对象的引用列表，而只有应用程序才拥有外层的 `Window` 对象（该对象本身确实包含一个指向底层由窗口管理器拥有的 `WindowInner` 对象的引用）。`Window` 结构体还包含其他描述该窗口的应用程序相关状态。

## `WindowInner` 结构体

`window_inner` crate 定义了 `WindowInner` 结构体。它包含在屏幕上显示该窗口所需的状态和方法。

`WindowInner` 拥有一个 framebuffer，窗口的内容可以显示到它上面。该 framebuffer 以组成它的像素类型作为类型参数。当窗口被渲染到屏幕上时，合成器（compositor）可能会根据像素类型以不同的规则来合成每个像素。目前，我们已经实现了普通的 RGB 像素和带 alpha 通道的像素。

应用程序的窗口与窗口管理器都持有指向同一个 `WindowInner` 对象的引用。应用程序可以在 framebuffer 中进行配置和绘制，而窗口管理器则可以显示该窗口并将其与其他窗口合成。

该结构体还包含一个事件生产者（event producer）。窗口管理器从键盘等 I/O 设备获取事件，并把它们推送到相应的生产者中。

## Window

`Window` 对象表示一个窗口，由应用程序所拥有。它包含自己的 profile、一个标题、一个消费者（consumer）以及一个 displayable（可显示对象）列表。消费者可以获取由窗口管理器推送到其 profile 中生产者的事件。

`Window` 提供了显示其中的 displayable 以及把自身渲染到屏幕上的方法。窗口管理器负责通过 framebuffer 合成器将它与其他窗口合成。

## displayable（可显示对象）

`displayable` crate 定义了 `Displayable` trait。`Displayable` 是一种能够把自己显示到 framebuffer 上的元素。它通常由基本图形组成，并作为窗口的一个组件，例如按钮或文本框。目前，我们已经实现了 `TextDisplay`，即一段文本块。将来，我们还会实现其他种类的 displayable。

一个应用程序可以拥有多个 displayable，并在其窗口中显示任意类型的 `Displayable`。

## WindowManager

`window_manager` crate 定义了 `WindowManager` 结构体。该结构体由活动窗口的 profile、已显示窗口的列表和隐藏窗口的列表组成。隐藏的窗口会被其他窗口完全覆盖。该结构体实现了操作这些列表的基本方法，例如添加或删除窗口。

`WindowManager` 结构体包含一个位于最底层的 framebuffer（表示背景图像），以及一个最终的 framebuffer（包含浮动的窗口边框和鼠标箭头）。在刷新某个区域时，它按照 背景 -> 隐藏列表 -> 已显示列表 -> 活动窗口 -> 最上层 的顺序渲染各个 framebuffer。为了获得更好的性能，它还提供了若干用于更新矩形区域或若干像素的方法。

该结构体定义了处理通用事件的循环、处理键盘事件的循环以及处理鼠标事件的循环。Theseus 会把它们初始化为任务来处理输入。窗口管理器结构体提供了对窗口列表进行操作的方法，作为对这些输入的响应。当我们用鼠标拖动某个窗口时，它可以移动该窗口，或者把其他事件传递给活动窗口。活动窗口的拥有者应用程序可以处理这些事件。

`window_manager` crate 拥有一个 `WINDOW_MANAGER` 实例，其中包含所有已存在的窗口。它调用 `WindowManager` 的方法来管理这些窗口。
